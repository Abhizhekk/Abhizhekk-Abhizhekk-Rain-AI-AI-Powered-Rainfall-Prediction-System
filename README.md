# 🌧️ Rain AI — AI-Powered Rainfall Prediction System

**Rain AI** is a machine learning weather intelligence application that predicts the probability of rainfall for any city using recent atmospheric patterns such as humidity and pressure trends over the past 14 days.

The platform combines real-time weather data, a trained ML model, and an interactive analytics dashboard to deliver simple and understandable weather insights.

---

## 🚀 Features

* 🌍 City-based rainfall prediction
* 📊 14-day humidity & pressure trend visualization
* 🤖 Machine learning prediction model (TensorFlow / Keras)
* 🌡️ Real-time weather API integration
* 📈 Interactive analytics dashboard
* 🎨 Modern glassmorphism UI
* 📍 Location-aware weather insights

---

## 🧠 How It Works

1. User enters a city name
2. App fetches recent weather data from API
3. Data is cleaned and preprocessed
4. ML model analyzes humidity & pressure patterns
5. Model predicts rainfall probability
6. Dashboard displays prediction and trend graphs
